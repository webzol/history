## 还需做的一件事：确认声明入口

微信把「现网版本」和「提审 / 开发版本」的隐私声明做成**两套独立入口，互不影响**。审核通知没写是通过哪一个入口，需在后台确认：

| 入口 | 路径 | 影响的版本 |
|---|---|---|
| 入口①（现网） | 设置 → 服务内容声明 → 用户隐私保护指引 | 已发布（线上）版本 |
| 入口②（提审 / 开发） | 管理 → 版本管理 → 提交代码审核 → 信息填写页 | 开发版 / 体验版 |

**要求：两个入口都要有这条指引**，否则可能出现「现网能弹、体验版不弹」或反之。请确认后回复两个入口各自的状态。

## 声明的隐私类型（核对）

- 需声明的类型：**「使用你的相册（仅写入）权限」**
- 对应接口：`wx.saveImageToPhotosAlbum`（仅用于保存用户主动生成的分享海报）
- 用途文案可填：
  > 为了将用户主动生成的历史分享海报保存到设备相册，申请相册的仅写入权限，仅用于保存用户选定的海报。
- ⚠️ **不要勾选「未采集隐私」**——勾了会导致相关接口被回收（保存海报报 `errno 112 / api scope is not declared`）。
- 本小程序**不读取**微信头像、昵称、手机号、位置、相册照片；随机身份由本地生成。
