# 史页 · 当前视觉规范（参考图风格）

**版本：v1.0｜2026-10-18**

> 这是当前开发使用的视觉基准。上一版 `ui/neo/` 与 `docs/UI设计说明.md` 已归档。
> 视觉源文件：`ui/reference/home-v3.html`；截图：`ui/reference/home-final.png`。

---

## 1. 关键词

**宣纸、淡墨、手绘建筑、朱砂印章、浅色磁贴、大留白、宋体标题。**

不是“极简白卡 + 赭石青黛”的 neo 风格，而是更接近用户上传参考图的“纸上营造”：

- 背景像一张铺开的宣纸，右侧有极淡的竖排书法。
- 内容放在暖白大圆角卡片上，阴影很轻。
- 插画是低对比手绘线稿，不是写实照片。
- 朱砂只做印章和少量强调。
- 功能入口用浅灰/米色/白色磁贴，不是图标+文字列表。

## 2. 色彩

| 角色 | 色值 | 用法 |
|---|---|---|
| 宣纸 | `#F6F1EA` | 页面底 |
| 暖白 | `#FCFBF8` | 大卡、搜索框、按钮 |
| 墨 | `#1F1D19` | 标题、正文重点 |
| 次墨 | `#5F5A52` | 正文 |
| 淡墨 | `#8C857A` | 辅助信息 |
| 朱砂 | `#A34A3E` | 印章、当前节点、少量强调 |
| 浅蓝灰 | `#A9BCC4` | 近现代辅助色 |
| 深蓝灰 | `#7E9A9A` | 近现代文字/图标 |
| 唐代米 | `#F3EFE6` | 盛唐卡片底 |
| 磁贴灰 | `#EEF0F0` | 时间轴磁贴 |
| 磁贴米 | `#F1E8DD` | 朝代磁贴 |
| 磁贴白 | `#FBF9F6` | 事件磁贴 |
| 分隔线 | `rgba(70,58,45,.10)` | 卡片边、底栏 |

**规则**

- 朱砂不铺大面积背景；只做印章、当前点、少量短横线。
- 近现代用蓝灰，不用朱砂大面积标记。
- 插画线稿用暖灰/赭色（`#B6A28B` 附近），不要高饱和。

---

## 3. 字体

| 用途 | 字体 |
|---|---|
| 字标、标题、年份、人名 | Songti SC / STSong / SimSun |
| 正文、按钮、标签 | Noto Sans SC / PingFang SC |
| 引文、题眼 | KaiTi / STKaiti |

- 字标“史页”字重 400，字距 0.1em。
- 大标题不要加粗；靠字号和留白建立层级。
- 正文 21–26rpx（小程序），辅助 16–19rpx。

---

## 4. 版式

- 设计基准：390×844；小程序 750rpx 宽，1px ≈ 1.923rpx。
- 页面左右边距：46rpx。
- 主要卡片圆角：38–42rpx；磁贴：34rpx；小卡：30rpx。
- 阴影：`0 20rpx 46rpx rgba(90,70,50,.06)`，不要重投影。
- 顶部：自定义导航栏；首页只放品牌“史页”，**不放搜索/菜单**；时间轴/发现/我的保留并给微信胶囊留空间。
- 底部：自绘四栏，固定在底部，预留安全区。
- 背景：`paper-bg.png` 以 `aspectFill` 铺满，不重复。

---

## 5. 首页结构（当前已实现）

1. 顶部：只保留 `史页` 字标（按用户要求移除搜索/菜单）。
2. 日期：`10月18日 · 今天`。
3. 今日史事：白卡，标题 + 事件句 + 参考图裁切的宫殿插画（含朱砂“史载”印章）。
4. 四磁贴：时间轴、朝代、人物、事件。
5. “沿着时间走”：盛唐气象卡（整卡使用用户提供的 `tang-bg.jpg`，按卡片比例裁切；左文右楼阁）+ 右侧蓝灰卷轴裁切装饰。
6. 近现代入口：与盛唐卡同规格的白卡，标题“百年中国”+ 一句说明；右侧 1840/1949 蓝灰年份，不放印章。
7. 底部四栏：首页（实心）/ 时间轴 / 发现 / 我的。

当前首页由 `miniprogram/data/history.js` 驱动：

- 日期动态生成。
- 今日史事、盛唐气象、百年中国来自本地真实数据种子。
- 点击磁贴会打开真实数据的 ActionSheet / Modal；时间轴跳转独立页。
- 首页“今日史事”目前是编辑精选（汉武帝），精确日期匹配待内容审校。

## 6. 插画与素材

| 素材 | 文件 | 说明 |
|---|---|---|
| 宣纸背景 | `miniprogram/assets/paper-bg.png` | 750×1624，含噪点、竖排淡墨、细线；由 `tools/make_paper_bg.py` 生成 |
| 宫殿 | `miniprogram/assets/palace.png` | 按用户要求从参考图裁切，含“史载”印章，背景 `#FCFAFB` |
| 盛唐背景 | `miniprogram/assets/tang-bg.jpg` | 用户新图按卡片比例 2048×756 裁切，整卡背景 |
| 蓝灰卷轴 | `miniprogram/assets/scroll-accent.png` | 从参考图“盛唐气象”右侧裁切，作为卡片旁的装饰 |
| 近现代 | 白卡 + 蓝灰年份 | 与盛唐卡同圆角/阴影；右侧 1840/1949；不放印章，不使用手绘轮船 |
| 图标 | `miniprogram/assets/icons/*.png` | 透明 PNG，48×48，1.4px 线宽 |
| 旧版源 SVG | `ui/reference/assets/*.svg` | 早期原创稿，仅归档；当前首页不使用 |

**规则**

- 当前 hero 插画与盛唐背景是从用户提供的参考图/新图裁切的，仅用于本项目原型；正式上线前必须确认授权或替换为有授权素材。
- 用户明确要求：不要自行手绘、不要去找图替代；按参考图 1:1 还原。
- 插画 PNG 的背景色与卡片底色绑定；改卡片色必须重新裁切/导出。
- 不要使用 AI 伪造历史照片；没有可靠图像时用参考图裁切或印章/剪影。

## 7. 与上一版 neo 的区别

| 维度 | neo 版 | 当前参考图版 |
|---|---|---|
| 背景 | 纯浅米 + 简牍线 | 宣纸 + 竖排书法暗纹 |
| 卡片 | 24px 白卡 | 22–26px 暖白卡 + 更轻阴影 |
| 标题 | 宋体，较克制 | 更大字号，字标感更强 |
| 插画 | 少量线稿 | 大尺寸手绘建筑插画 |
| 功能入口 | 横向文字条目 | 四枚浅色磁贴 |
| 近现代 | 青黛 + 独立时间轴 | 蓝灰入口 + 后续双轴 |
| 底部 | 细线四栏 | 参考图式四栏，首页实心 |

## 8. 下一页面的设计规则

- **时间轴**：顶部“古代 / 近现代”切换；事件用白卡 + 年份 + 细线；当前事件朱砂点/短横线。
- **人物**：人物像用姓氏印章/剪影；姓名大宋体；引文楷体；生平时线；关系一行。
- **事件**：大年份 + 标题；事实卡 2×2；背景/经过/影响；史料来源。
- **搜索**：大圆角搜索框；白卡结果；相关搜索 + 热门搜索；古今结果并列。
- **近现代**：蓝灰作为辅助色；朱砂印章只保留在 Hero 插画内，盛唐卡和百年中国卡都不放印；1840–2024，不追新闻。
