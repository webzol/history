## 1. 设计概念

**现代新中式，不是复古。**

- **纸**：浅米宣纸底色 `#F5EFE4`，叠加极低透明度的简牍暗纹（竖向竹简 + 横向编绳）。
- **白**：内容放在大圆角白色卡片上，柔和轻阴影，像一页页摊开的纸。
- **墨**：标题用清雅宋体，正文用黑体，引文用楷体；层级靠留白和字号，不靠重色块。
- **色**：低饱和赭石 + 青黛；朱砂只做右上角小印章、当前节点和关键动作。
- **空**：大量留白，页面不堆满；一屏只讲一个主题。
- **双轴**：**赭石 = 古代史，青黛 = 近现代史**；两者在时间轴一级切换，不是“更多”里的二级入口。

一句话：**像一本可以滑动、可以搜索、可以跳转的纸书，古代与近现代都在同一张桌上。**

## 2. 视觉系统

### 2.1 色彩

| 角色 | 色值 | 用法 |
|---|---|---|
| 宣纸 | `#F5EFE4` | 页面底色 |
| 素白 | `#FFFDFA` | 大圆角卡片、搜索框、按钮底 |
| 墨 | `#2D2923` | 主标题、正文重点 |
| 次级墨 | `#6B6358` | 正文、说明 |
| 淡墨 | `#9A9082` | 时间、来源、辅助信息 |
| 赭石 | `#A9825E` | **古代史**时间节点、年份、强调 |
| 青黛 | `#5F736E` | **近现代史**时间节点、年份、强调 |
| 朱砂 | `#B04A3A` | 小印章、当前状态、少量关键动作 |
| 旧纸 | `#F1E6D7` | 引文、人文提示块 |
| 青黛浅 | `#E8EEEA` | 近现代引文、世界同期块 |
| 细线 | `rgba(90,75,55,.10)` | 卡片边、分隔、时间轴 |

**语义规则**：赭石与青黛负责“时代”，朱砂负责“印章/现在”。不要让朱砂做大面积按钮或背景。

### 2.2 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题、年份、人名 | 宋体：Songti SC / STSong / SimSun | 清雅、横细竖粗，不靠书法字体 |
| 正文、按钮、标签 | 黑体：Noto Sans SC / PingFang SC | 保证小字号可读 |
| 引文、题眼、人物一句话 | 楷体：KaiTi / STKaiti | 只用于短句 |
| 数字 | 宋体 | 让 1005、1911、1949 成为视觉符号 |

实际小程序不建议整包引入大字体；标题先用系统宋体，P1 再子集化思源宋体。

### 2.3 版式与质感

- 设计基准：**750rpx**；本稿按 374px 宽绘制，1px ≈ 2rpx。
- 页边距：**48rpx**；卡片内边距：**28–36rpx**。
- 卡片圆角：**44–52rpx**；按钮圆角：**28rpx**。
- 阴影：`0 12px 30px rgba(96,75,50,.075)`，只做“轻轻浮起”，不做重投影。
- 图标：1.2–1.3px 细线，圆角端点；不使用面性图标。
- 背景纹理：浅米底 + 3% 左右的竖向简牍线；卡片内部局部出现，不干扰文字。
- 触控区 ≥ 88rpx；底部安全区预留。

### 2.4 印章

- 右上角固定一枚朱砂小印章（首页/时间轴用“史”，详情页放在卡片右上角）。
- 印章尺寸 24–30px（48–60rpx），圆角 3px，轻微旋转 2°，带一点点朱砂阴影。
- 印章文字随页面变化：九一八（九一八事变）、宋（北宋）、民（中华民国）、辛亥（辛亥革命）、豫才（鲁迅）。
- 印章是记忆点，不是按钮；不要每张卡都盖。

## 4. 近现代史怎么进产品

近现代不是“古代史做完再加”，而是从信息架构开始并列：

- **一级切换**：时间轴顶部“古代 / 近现代”，不是“更多”里的入口。
- **独立时间轴**：1840–1911 晚清、1912–1949 民国、1949–1978 新中国、1978–2012 改革开放、2012– 新时代。
- **独立内容类型**：近现代事件、近现代人物、近现代专题都可以独立搜索、收藏、分享。
- **色彩语义**：古代用赭石，近现代用青黛；朱砂印章贯穿两者。
- **内容边界**：1840–2024，**不追新闻**；以权威公开史料和官方出版著作为主，敏感议题由历史审校把关。
- **首页平衡**：Hero 用近现代（九一八），人物/事件卡用古代（苏轼/澶渊之盟），专题用近现代（百年中国）；一屏之内古今并置。

### 近现代示例内容

- 时间轴：1840 鸦片战争、1911 辛亥革命、1919 五四运动、1931 九一八事变、1949 中华人民共和国成立、1978 改革开放、2001 加入 WTO、2021 全面建成小康社会。
- 事件：1911 辛亥革命（本稿示例）。
- 人物：鲁迅（本稿示例）。
- 专题：百年中国 1840–1949、改革开放 1978–2024。

## 5. 关键组件

### 5.1 顶部

- 状态栏 + 微信胶囊必须预留。
- 首页/时间轴：字标“史页”或页面名 + 搜索/筛选 + 右上角朱砂小印章。
- 详情页：返回 + 页面类型 + 分享/收藏；印章放进 Hero 卡片右上角。
- 搜索页：返回 + 大圆角搜索框；搜索框右侧止于胶囊左侧。

### 5.2 卡片

- 大圆角白卡：`#FFFDFA`、24–26px 圆角、柔和阴影、极浅描边。
- 人物卡：姓氏印章/剪影、姓名、生卒、身份、楷体一句。
- 事件卡：年份、标题、一句话、类型标签。
- 专题卡：近现代用青黛左边线，古代用赭石细节。
- 事实卡：2×2 网格，细线分隔，标签小、值大。
- 引文卡：古代旧纸底，近现代青黛浅底；楷体，居中，少量。

### 5.3 时间轴

- 左侧年份，中间细线 + 节点，右侧白卡。
- 古代线：赭石；近现代线：青黛。
- 当前事件：朱砂节点 + 对应时代色左边线 + 轻阴影。
- 人物图层：默认关闭；头像圆点 + 开关。
- 缩放：MVP 用“朝代/世纪/年”或“古代/近现代”分段控件，不做双指缩放。

### 5.4 图标

- 线性、细笔、圆角：搜索、返回、分享、收藏、筛选、首页、时间轴、发现、我的。
- 图标不填色；当前 Tab 用赭石/青黛着色 + 顶部细线。

## 6. 小程序落地建议

- **字号**：本稿是视觉概念，部分辅助文字偏小。实际正文建议 **≥ 24rpx**，辅助 ≥ **20rpx**，标题 44–72rpx；放不下时减少首屏信息，不要继续缩字号。
- **单位**：布局用 `rpx`，1px 细线用 `px`；底部安全区用 `env(safe-area-inset-bottom)`。
- **卡片**：圆角 44–52rpx；阴影用两层（大柔和 + 小贴地），避免“浮夸投影”。
- **纹理**：宣纸底 + 3% 简牍线用 CSS `repeating-linear-gradient` 或一张很小的 SVG/PNG 平铺；不要用大图，避免包体和性能问题。
- **字体**：系统宋体/黑体/楷体优先；不要为了古风引入 5MB 字体包。
- **颜色**：用 CSS 变量统一管理；赭石=古代，青黛=近现代，朱砂=印章/当前。
- **内容渲染**：Block JSON + 自定义组件；不要整篇塞 `rich-text`。
- **图片**：人物像优先公有领域/博物馆开放素材；没有可靠图像时用姓氏印章/剪影，不用 AI 伪造历史照片。
- **深色模式**：P1；宣纸 → 墨色，白卡 → 深灰，赭石/青黛/朱砂保留。
- **可访问性**：对比度 ≥ 4.5:1；点击区 ≥ 88rpx；支持字号放大。

## 7. 需要你确认

1. **这版现代新中式方向**：浅米宣纸、白卡、赭石/青黛、朱砂小印章，是否是你要的感觉？
2. **古今双轴**：首页/时间轴把“近现代”作为一级入口，是否同意？还是希望古代史和近现代史各做一个独立 Tab？
3. **首页古今比例**：现在 Hero 是近现代（九一八），人物/事件是古代（苏轼/澶渊之盟），专题是近现代（百年中国）。这个平衡是否合适？
4. **下一步**：确认后我可以把 10 页串成可点击网页原型，再先落首页、时间轴、人物 3 页的 WXML/WXSS。
